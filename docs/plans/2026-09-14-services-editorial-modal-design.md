# Services Editorial Modal

## Direction

The service detail overlay should read like a premium studio dossier rather than a SaaS interface. The design uses an asymmetric editorial grid, oversized service numbering, restrained typography, thin rules, and a single electric-blue accent.

## Structure

- Minimal header with studio context, specification label, and close control.
- Narrative column with service index, title, tagline, and supporting copy.
- Specification column with numbered deliverables and a plain-text standards index.
- Expected outcome integrated as the third numbered specification section, using quieter editorial body copy rather than a separate pull-quote composition.
- Persistent footer with one primary project CTA and previous/next service navigation.

## Interaction and responsive behavior

Existing service data, deep links, keyboard navigation, focus behavior, Escape handling, and previous/next controls remain intact. The desktop dossier fits within the popup without an internal scroll area. On small screens the two-column dossier becomes a single scrolling column while the CTA and arrow navigation stay accessible in the footer. Reduced-motion preferences continue to use the site's global fallback.

## Visual constraints

Avoid nested cards, decorative gradients, pill badges, checklist icons, exaggerated blur, and springy modal motion. Use the existing warm paper background and type system, with Georgia reserved for editorial statements to create contrast without adding another network dependency. An 18px outer radius and a compact 12px CTA radius soften the composition without turning it back into a collection of rounded cards.
